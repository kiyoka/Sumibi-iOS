# Sumibi 1.1.0 App Store更新情報

## このバージョンの新機能

- 選択中の文字列だけをAIで変換できる「範囲を変換」を追加
- モデルごとの変換回数、入出力トークン数、概算利用料金を確認できる利用状況画面を追加
- 「さらに変換候補を取得」で、同じ読みを持つ別の漢字や表現をこれまでより幅広く提案
- 保存済みAPIキーの末尾4文字を表示し、使用中のキーを確認できるよう改善
- 範囲選択した文字列を直接変換できるようになったため、クリップボードからの読込機能を廃止
- その他、ユーザビリティを改善

## 変更点の詳細

- 選択範囲がある場合は変換キーを「範囲を変換」に変更し、選択中の文字列だけを変換
- 利用状況として、モデル別の集計開始日時、変換回数、入力・出力トークン数、概算利用料金を表示
- 追加候補の取得時に、現在の変換結果とは異なる同音異義語を最大5件提案するよう改善
- 追加候補の上限を7件から12件へ拡張
- 単語だけの入力では同音異義語を幅広く提案し、文章では周辺の文脈から著しく外れる候補を除外
- 適切な候補が少ない場合は、不自然な候補で数を補わない
- タイプミス補正、ひらがな、カタカナ、漢字を多く使った表記、送り仮名をひらいた表記、英訳の各候補は継続して提供
- 候補ボタンを文字列の長さに応じた幅へ変更
- 保存済みAPIキーの末尾4文字を設定画面に表示
- APIキー削除時の確認画面を追加
- 設定内容を編集した場合だけ保存ボタンを有効にし、保存後は無効化して保存完了を分かりやすく表示
- API設定の保存後にキーボードを閉じ、保存結果を確認しやすく改善
- 選択範囲の直接変換に置き換える形で、クリップボードからの読込機能を廃止

## App Store Connect登録時の確認

- キーボードが写っているスクリーンショットは、1.1.0の最新UIで撮り直す
- Appプレビュー動画は1.1.0の実機画面を録画して作成する
