## このバージョンの新機能（日本語・確認用案）

- 打鍵の勢いをためて変換時に楽しめる、ドラゴン・宇宙船・猫・魔法使いの4種類のゲーム風演出を追加。設定でオンにできます
- AIと会話して、使い方や利用状況、今後の概算費用を質問できる「チャットで質問」を追加。モデルや音・振動の設定変更も相談できます
- GPT-6 Sol・GPT-6 Lunaを選択できるモデル設定を追加。自由入力したモデル名もそのまま使えます
- 辞書による同音異義語の追加候補を導入し、候補の出所を表示。「ten」「nakaguro」「.」から中黒「・」も選べるように改善
- 記号辞書を追加し、「hoshi」から星印、「maru1」から丸数字などを追加候補で選べるように改善
- キーの種類に応じて音色が変わる、独自のキークリック音を追加
- iOS 27で候補バーの文字がぼやける問題を修正
- その他、操作性と安定性を改善

概算費用は端末内の利用統計に基づく参考値で、APIの実際の請求額・残高ではない。
チャットは設定済みの第三者AIとの会話であり、人間への問い合わせではない。
文言は利用者の確認後に確定する。

## What's New（英語・確認用案）

- Added four optional game-inspired effects: a dragon, spaceship, cat, and wizard. Build energy as you type and release it when converting text.
- Added an AI chat for help with Sumibi, usage statistics, and estimated future API costs. You can also review proposed changes to model, sound, and haptic settings.
- Added model selection for GPT-6 Sol and GPT-6 Luna while preserving custom model names.
- Added dictionary-supplemented homophone candidates with source labels, including the Japanese middle dot “・” for “ten”, “nakaguro”, and “.”.
- Added a symbol dictionary, including stars for “hoshi” and circled numbers for “maru1”.
- Added original key-click sounds that vary by key type.
- Fixed blurry text in the candidate bar on iOS 27.
- Other usability and stability improvements.
