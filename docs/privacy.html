Sumibi

プライバシーポリシー

Sumibiが取り扱うデータと、Apple Private Cloud Computeおよび利用者が設定した外部AIへの送信について説明します。

1. 適用範囲

本ポリシーは、iOSアプリおよびカスタムキーボード「Sumibi」（以下「本アプリ」）に適用されます。対応する端末ではApple Private Cloud Compute（PCC）を優先して日本語変換と相談チャットを行います。PCCを利用できない場合や日次上限に達した場合は、設定済みの外部AIを使用できます。

2. AIへ送信するデータ

PCCを優先する設定では、変換操作のたびに次のデータをAppleのPCCへ送信します。PCCの日次上限に達した場合や端末がPCCに対応していない場合、保存済みのAPIキーと送信同意がある外部AIへ切り替えます。外部AIへの送信先はアプリ内で確認できます。

  • 変換対象として入力した文字列
  • 変換に必要な最小限の周辺文脈
  • 本アプリに登録されているユーザー辞書の全内容
  • 使用中の文体プリセットに登録されている変換プロンプト
  • 外部AIを使用する場合は設定されたモデル名

アプリに同梱した変換候補の索引（SudachiDict由来の辞書・Mozc由来の記号辞書）と、中黒用の内蔵カスタム辞書は端末内で検索し、AIへ送信しません。上記のユーザー辞書は、利用者自身が登録した辞書を指します。

相談チャットでは、PCCを優先し、会話内容、変更対象の現在値、アプリのモデル選択肢、現在日時・タイムゾーン、モデル別の利用統計（集計開始日時・回数・トークン数・概算料金）をAppleへ送信します。PCCの日次上限後やPCCを利用できない端末、優先設定をオフにした場合は、同意済みの外部APIへ同じ情報を送信します。これらを基に、使い方の説明、費用の見積もり、設定変更の提案を生成します。APIキーは認証にのみ使用し、会話には含めません。変換した文章、ユーザー辞書とプリセット情報は相談チャットへ追加で送信しません。

外部AIの送信同意は接続先ごとに保存します。同意していない送信先へ自動的に切り替えることはありません。外部APIの利用には料金が発生する場合があります。

3. 利用目的

送信データは、日本語変換候補、使い方の説明、費用の見積もり、設定変更の提案を生成して利用者へ返すために使用します。費用の見積もりはこの端末の統計に基づく概算であり、実際のAPI請求額や残高ではありません。本アプリの開発者は、広告、利用者の追跡、プロファイリング、データ販売の目的では使用しません。

4. 端末内に保存するデータ

  • APIのURL、モデル名、各種設定、ユーザー辞書、文体プリセットは、アプリとキーボード拡張が共有する端末内領域に保存します。
  • APIキーはAppleのKeychainに保存し、APIへの認証にのみ使用します。
  • 相談チャットの会話履歴は画面を閉じると破棄します。PCCの変換・チャット回数は端末の現地時刻の暦日ごとに保存し、利用枠の確認日時と上限到達を確認した日時も端末内に保存します。変換した文章は履歴に残しません。外部AIのモデルごとの使用回数、トークン数、概算料金も端末内に保存します。
  • 本アプリは、これらの設定、APIキー、ユーザー辞書、文体プリセットをiCloudへ同期しません。

5. ログ、保存および第三者の取り扱い

本アプリの開発者が運営するサーバーは経由しません。また、開発者は変換対象、周辺文脈、ユーザー辞書、文体プリセット、APIキーを収集または記録しません。

AppleのPCCと外部API提供者は、それぞれのプライバシーポリシー、利用規約、データ保持方針に従ってデータを処理します。外部AIを利用する場合は、アプリ内に表示される送信先を確認し、提供者の方針を確認したうえで同意してください。本アプリは、送信先による保存、学習利用、削除を管理できません。

6. 同意の取消しとデータの削除

  • PCCへの変換・相談チャット送信は、アプリの「変換とチャットでAppleのAIを優先」をオフにすると停止できます。オフにした場合、設定済みの外部APIを使用します。
  • 特定の外部AIへの送信は、その接続先を選択し、「外部AI（オプション）」欄の同意スイッチをオフにすると停止できます。
  • APIキーはアプリの「APIキーを削除」からKeychainより削除できます。
  • ユーザー辞書は、アプリのユーザー辞書欄から登録内容を削除して保存できます。
  • 文体プリセットは、アプリの文体プリセット欄から削除できます。
  • API提供者が保持するデータの確認や削除は、その提供者へ直接依頼してください。
  • アプリを削除すると、設定、ユーザー辞書、文体プリセットなどのアプリデータはiOSの仕組みに従って削除されます。KeychainのAPIキーを確実に削除するには、アプリを削除する前に「APIキーを削除」を実行してください。
