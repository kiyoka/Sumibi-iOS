# 1.3.0 実機確認の進め方

Issue #131。今回の配信予定ビルドで確認する。1.2.0からの更新確認と新規インストール確認は分ける。
すでに開発版を使っている端末への上書きだけでは、App Store版1.2.0からの更新テスト完了にはしない。

## 1. 更新後の設定保持

アプリを削除せず上書きする。更新前後で次が同じか確認する。
APIキーそのものは記録・撮影せず、保存済み表示と実際の変換成功で確認する。

- [x] API設定が以前のまま保持されている
- [x] ユーザー辞書が保持されている
- [x] 文体プリセットが保持されている
- [x] 利用状況が保持されている
- [ ] 第三者AIへの送信同意が保持されている
- [ ] 音・触覚・変換完了時の振動・ゲーム演出のON/OFF・選択テーマ
- [ ] 旧モデルを保存していた場合、勝手にGPT-6 Solへ変更されていない

## 2. キーボードの基本機能

メモアプリでは空の新規メモを開き、他のメモ一覧は撮影しない。

- [ ] `ashitaha tosyokan ni ikimasu .` を変換し、日本語になる
- [ ] `osameru` を変換し、追加候補の取得・選択・Undoができる
- [ ] `Meeting: ashitaha tosyokan ni ikimasu .` のローマ字部分だけを選択し、「範囲を変換」で英語部分を維持できる
- [ ] 記号・数字・削除長押し・地球儀・キーの拡大が動く
- [ ] 登録した辞書と文体プリセットが反映され、不要な場合は元の選択へ戻せる
- [ ] フルアクセスOFF／送信同意OFFで変換を送信せず、英字入力はできる
- [ ] 通信エラー後、通信を戻して再試行できる

## 3. モデルとAIチャット

API使用料が発生する。設定変更を試す際は、元の値を記録し確認後に戻す。

- [ ] モデル欄でGPT-6 Sol・Luna・自由入力を選択できる。確認後に元のモデルへ戻す
- [ ] 「チャットで質問」にAIとの会話である旨が表示される
- [ ] 「Sumibiの使い方を教えて」に操作方法を回答する
- [ ] 「今どれくらい費用がかかっていますか？」に利用状況の概算と整合する回答をする
- [ ] 続けて「今後15日では？」と質問できる。記録不足なら不足を説明する
- [ ] 「音と振動を全部止めたい」で設定案を表示し、適用前は設定が変わらない
- [ ] 「適用する」で反映し、確認後に元の設定へ戻せる
- [ ] 画面を閉じて開き直すと前の会話が消えている

## 4. 4種類の演出

アプリの「遊び心のあるキーボード」からゲーム演出をONにする。
設定のテーマ選択と、キーボード左のキャラクタータップの両方を試す。

- [ ] ドラゴン・宇宙船・猫・魔法使いが一周し、選択が設定にも残る
- [ ] 速く打つほどゲージがたまり、休むと滑らかに減る
- [ ] 変換で放出演出が出て、少ない／多いエネルギーで違いがある
- [ ] 猫は右端でピンクのボールをくわえ、拡大した正面ポーズで約2秒止まり自然に消える
- [ ] 候補・Undoが隠れず、猫と重なったキーも操作できる
- [ ] 演出OFFで通常の高さ・表示へ戻る
- [ ] Light／Dark、横画面、記号展開で見切れず、iOS 27でも候補・ステータス文字が読める
- [ ] 「視差効果を減らす」ONで動きを抑える。試した後は端末設定を元へ戻す

## 5. クリック音

- [ ] 文字・削除・空白などで音が異なり、長押しと音が同期する
- [ ] Sumibiのクリック音OFF／ONと保存が動く
- [ ] コントロールセンターで音量を上下すると追従し、音量0で鳴らない
- [ ] 消音モードで鳴らず、解除後の打鍵で再開する
- [ ] 他アプリの音楽・動画を再生しても共存する
- [ ] キーボードを閉じて開く、他アプリの音声機能を使って戻る操作後も、古いクリックがまとめて鳴らない

## 6. 同梱辞書・中黒・記号・ライセンス（#132・#133）

2026-10-16に1.3.0の対象へ追加し、作業ブランチへ実装済み。2026-10-17に同梱辞書を含む1.3.0／Build 4をiPhone 17eへ上書きインストールし、起動を確認した。

- [x] 「さらに変換候補を取得」で辞書候補が表示される（利用者による実機確認）
- [ ] `hashi`・`kami`の追加候補を取得し、LLM候補の後に辞書候補が重複なく表示される
- [ ] 「LLM／辞書」の注釈を識別でき、候補を選んでも本文に注釈は入らない
- [x] `ten`・`nakaguro`・`.`から中黒「・」が表示される（利用者による実機確認）
- [ ] ユーザー辞書未登録でも、`ten`・`nakaguro`・`.`から中黒「・」を選択できる
- [ ] `hoshi`／`hosi`から「☆」「★」、`maru1`／`maruichi`から「①」を選択できる
- [ ] `maru2`・`yajirushi`・`mugendai`から「②」・矢印・「∞」を選択できる
- [ ] 記号の候補がLLMと重複せず、選択後のUndoで入力した読みへ戻る
- [ ] 範囲変換・候補選択・Undoが動き、文章中のピリオドや論文スタイルを勝手に中黒へ変えない
- [ ] 設定からライセンス画面を開き、通信なしでMIT・Apache-2.0・著作権・LEGAL全文を閲覧できる
- [ ] ライセンス画面からMozcの出典・加工内容とBSD条件を含む原文全文を閲覧できる
- [ ] 候補の読み込み・連続変換・ゲーム演出併用で、キーボードが終了したり動作が重くなったりしない

## 結果の記録

2026-10-17：iPhone 17eへ上書きインストールした#132入りの1.3.0／Build 4について、

個別の同音異義語・候補順序・重複・本文への挿入・Undo・ライセンス閲覧・負荷については、この報告だけでは確認済みとしない。

2026-10-17：#133の記号辞書を含む1.3.0／Build 4の開発用署名Release版をiPhone 17eへ上書きインストールし、起動を確認した。
利用者から「うまく動きました」と報告を得た。個別の記号・Undo・ライセンス閲覧・負荷・TestFlightでの確認までは、この報告だけでは確認済みとしない。

2026-10-16：iPhone 17e／iOS 27.0.1、1.3.0／Build 4の開発用署名Release版で、
利用者からAPI設定・辞書・文体プリセット・利用状況が以前のまま保持されていると報告を得た。
更新前のアプリのインストール元は未確定のため、App Store版1.2.0からの更新確認完了とはまだ扱わない。
送信同意・各スイッチ・テーマの保持、主要機能の動作はこの報告に含めていない。

更新前の版、確認した項目と未確認項目を記録する。APIキーや会話の私的な内容は記録しない。
