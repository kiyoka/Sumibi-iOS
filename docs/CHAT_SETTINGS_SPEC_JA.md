# チャットによる設定変更の仕様（Issue #12）

状態：2026-10-04に仕様確定。実装済み。iPhone 17eでモデル一覧の案内を確認済み。

要望：モデルなどの設定を、チャットで会話しながら変更できるようにする。通信タイムアウトは15秒固定とする。

## 目的

設定項目の名前や操作場所を覚えなくても、「もっと安いモデルにして」「振動を止めて」のような日本語で設定を変更できるようにする。現在の設定について質問し、説明を読んでから変更することもできる。

## 画面と基本操作

- 設定アプリに「チャットで設定」へのNavigationLinkを追加し、専用画面へ遷移する。
- 会話履歴、入力欄、送信ボタンを表示する。最初に「低コストのモデルにしたい」「変換が終わったときの振動を止めたい」などの入力例を表示する。
- AIは日本語で回答する。設定の説明だけを求められた場合は、変更案を出さずに回答する。
- 変更が具体的に決まったら、回答に「変更前 → 変更後」の一覧と「適用する」ボタンを表示する。
- 「適用する」を押すまでは設定を変更しない。複数項目の変更はまとめて確認・適用する。
- 保存できたら「設定を変更しました」と表示し、同じ変更案の適用ボタンを無効にする。親画面へ戻ったときも保存後の値を表示する。
- 各変更案は、その提案時点の設定を基準にする。他の操作で設定が変わっていた場合は、差分を作り直してから適用する。

## 初回実装で変更できる項目

| 項目 | 会話で指定できる内容 | 制約・補足 |
| --- | --- | --- |
| 変換モデル | GPT-6 Sol、GPT-6 Luna、具体的なモデルIDの自由入力 | 「精度重視」はSol、「低コスト・高速重視」はLuna。曖昧なモデル名は聞き返す。自由入力モデルの利用可否はAPI側に依存する |
| キー入力時の振動 | ON／OFF | 変換完了時の振動とは区別する |
| 変換完了時の振動 | ON／OFF | 「変換したときの振動を止めて」の対象 |
| キークリック音 | ON／OFF | iOS本体の消音・音量設定にも従うことを説明する |

「振動を全部止めて」は両方の振動設定をOFFにする案を表示する。「振動を止めて」のように対象が曖昧な場合は、どちらを止めるか聞き返す。

APIキー・送信先URLの編集、ユーザー辞書やプリセットの選択・追加・編集・削除、利用統計のリセットは初回実装の対象外とする。対象外の依頼では、該当する設定画面を案内する。文体プリセットは会話では指定しにくいため、通常の「文体プリセット」画面で選択する。

## 会話例

| ユーザーの入力 | 期待する対応 |
| --- | --- |
| 「もっと安いモデルにして」 | GPT-6 Lunaへの変更案と変更前後を表示する |
| 「GPT-5.6 Terraを使いたい」 | `gpt-5.6-terra` を自由入力モデルとして提案する |
| 「今のモデルは何？」 | 保存済みのモデル名を答える。変更案は出さない |
| 「使えるモデルの一覧を見たい」 | 設定画面と同じ選択肢（GPT-6 Sol、GPT-6 Luna、自由入力）と補足を案内する。API側の利用可否を確認した一覧ではないと明示し、設定は変更しない |
| 「音と変換後の振動を止めて」 | キークリック音と変換完了時の振動をOFFにする案をまとめて表示する |
| 「論文スタイルに切り替えて」 | 設定画面へ戻って「文体プリセット」を開くよう案内し、変更案は出さない |

## AIへの接続と送信内容

- 保存済みのAPI接続設定とモデルを使って会話する。モデル変更後の次の送信では、新しいモデルを使う。
- API設定と第三者AIへの送信同意が完了していなければ、送信できない理由とAPI設定への導線を表示する。
- 初回のAPI接続設定は従来の画面で行う。設定済みAPIへの接続が失敗している場合も、従来の画面から修正できる。
- 会話文、変更対象の現在値、アプリのモデル選択肢を設定済みAIへ送信する。APIキーは認証にのみ使用し、会話や設定情報には含めない。ユーザー辞書とプリセット情報（名前・本文・選択状態）はこの会話には送信しない。
- 通常の変換用プロンプトと文体プリセットを設定チャットには適用せず、設定操作専用の指示を使用する。
- チャットの履歴は画面を開いている間だけ保持し、画面を閉じると破棄する。初回実装では履歴を端末へ保存しない。
- 画面に、会話内容が設定済みAIへ送信され、APIの利用料金が発生することを表示する。
- チャットにも利用状況のトークン数・概算料金を加算する。チャット送信回数を既存の「変換回数」には加算せず、別に「設定チャット回数」を表示する。APIがusageを返さない場合の扱いは現在の集計と同じとする。

## 通信タイムアウト

通信タイムアウトは従来どおり15秒固定とし、設定チャットも同じ値を使う。共有設定への保存項目や秒数の編集UIは追加しない。

会話で秒数の変更を依頼された場合は、15秒固定であることを説明し、変更案を出さない。

## 変更案の検証とエラー時の動作

- AIは回答文と変更案を分けて返す。アプリは変更案の項目名・型・値を検証し、許可した4項目だけを保存する。プリセット変更を含む案は拒否する。
- 不明な項目、空のモデル名、不正な応答は適用しない。タイムアウトの変更案も対象外として扱う。複数項目の一部だけを保存することもしない。
- 通信中は送信の連打を防ぎ、キャンセルできる。通信が終わる前に画面を閉じた場合も保存値は変わらない。
- 通信失敗、認証エラー、タイムアウト時は入力文を保持し、再試行できる。
- 自由入力モデルは、名前だけで利用可否を保証しない。適用後は既存の変換テストで接続を確認できるようにする。

## 実装時の完了条件

- モデル・音・振動の切替を、会話から提案して適用できる。
- プリセット変更の依頼には通常の設定画面を案内し、既存のプリセット設定を変更しない。
- 通信タイムアウトが15秒固定で、会話から変更されない。
- 質問だけの会話、曖昧な依頼、変更案の取り消しで保存値が変わらない。
- 変更前後を確認でき、適用結果が従来の設定画面とキーボードへ反映される。
- 未設定API、接続失敗、不正な変更案、通信キャンセルを適切に扱える。
- 既存の自由入力モデルと旧バージョンの保存設定を保持する。
- チャットのトークン数と料金を集計でき、変換回数とは区別できる。
- 実機で画面遷移、会話、変更の適用、設定の再読込、キーボードへの反映を確認する。
