# Sumibi 1.2.0 App Store素材更新案

## 更新方針

1.2.0ではキーボードの外観と操作時の演出が変わり、文体プリセット画面も追加されたため、スクリーンショットとAppプレビュー動画は撮り直す。

- 日本語版は、現在の実装を使って6枚を撮り直す
- 米国向けは、アプリ本体が日本語UIであることを隠さず、英語の見出しを載せた別画像を作る
- Appプレビュー動画は、Ember Glassと文体プリセットを含む1.2.0の操作を撮り直す
- APIキー、メールアドレス、通知、既存メモなどの秘密情報・個人情報を映さない
- iOS 26未満ではEmber Glassが無効になるため、外観紹介用の撮影にはiOS 26のiPhone 14 Plusを使う

## 日本語版スクリーンショット

| 番号 | 見出し案 | 撮影内容 |
| --- | --- | --- |
| 1 | ローマ字の文章を、自然な日本語へ | 通常変換が完了したメモと、現在のSumibiキーボード |
| 2 | 英字QWERTYの1画面で入力 | ローマ字入力中の画面。数字段と切り替え不要の配列も見せる |
| 3 | 候補から、好みの表現を選択 | `osameru`の追加候補と、文字列に合った幅の候補ボタン |
| 4 | 選んだ範囲だけを変換 | 英文を残し、選択したローマ字部分だけを変換する場面 |
| 5 | 出力言語をプリセットで切り替え | 韓国語プリセットの「設定なし／あり」の比較結果 |
| 6 | 記号一覧も、ワンタップで | 記号パネルとQWERTYキーボード |

1.1.0のスクリーンショットにあったユーザー辞書とプライバシー同意画面は機能として残るが、1.2.0の新機能を優先して5枚目を文体プリセットへ差し替える。必要なら7枚目以降として追加する。

## 米国向けスクリーンショット

## Appプレビュー動画

### 構成案（約30秒）

| 時間 | 画面と操作 | テロップ案 |
| --- | --- | --- |
| 0〜3秒 | 現在のSumibiキーボードを表示 | `AI日本語キーボード Sumibi` |
| 3〜11秒 | ローマ字文を入力し、変換する。変換中のEmber Glassも見せる | `ローマ字から、自然な日本語へ。` |
| 11〜17秒 | 英文中のローマ字部分だけを選択して変換する | `選んだ範囲だけ変換` |
| 17〜23秒 | `osameru`から複数の同音異義語候補を表示・選択する | `表現の候補も幅広く提案` |
| 23〜28秒 | 韓国語プリセットを選び、設定なし／ありの比較結果を見せる | `出力言語もプリセットで切り替え` |
| 28〜30秒 | Sumibiの設定画面またはロゴで締める | `Sumibi` |

## 撮影前チェック

- [ ] Version `1.2.0`、Build `3`が実機にインストールされている
- [ ] iPhoneをLight Modeにする
- [ ] ホーム画面は`Sumibi`と`メモ`だけの録画用ページにする
- [ ] メモは一覧を見せず、空の新規メモから開始する
- [ ] おやすみモードを有効にする
- [ ] APIキーや個人情報が映らない操作順にする
- [ ] 通常変換、範囲変換、追加候補、文体プリセットを事前に試す
- [ ] スクリーンショット6枚で時刻、テーマ、文字サイズを揃える
- [ ] 動画は30秒以内に収め、App Store Connectへ登録できる形式で書き出す
