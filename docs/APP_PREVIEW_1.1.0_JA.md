# Sumibi 1.1.0 Appプレビュー制作案

## 方針

- 1本目は、Sumibiの基本操作と1.1.0の主要機能を約27秒で紹介する
- iPhone 14 Plusの実機を縦向きで画面収録する
- 音声なしでも内容が伝わる短いテロップを使用する
- APIキー、メールアドレス、通知などの秘密情報・個人情報は映さない
- 端末を外から撮影せず、実機の画面収録だけを使用する
- 実際の操作順を保ち、アプリに存在しない動作を編集で表現しない

## 録画開始前のホーム画面

1. iPhoneをLight Modeへ変更し、録画中は表示モードを切り替えない
2. iPhoneのホーム画面に、録画専用の空のページを1ページ用意する
3. そのページには`Sumibi`と`メモ`の2つのアプリアイコンだけを配置する
4. 個人情報が分かるウィジェット、フォルダ、通知バッジは表示しない
5. `メモ`で録画専用の新規メモを作り、本文が空の編集画面を表示しておく
6. メモの一覧画面や既存のメモを録画中に表示しない。保存済みのメモのタイトルや内容が一瞬でも映らない操作順にする
7. `Sumibi`は終了しておき、録画中に以前の画面が一瞬表示されないようにする
8. おやすみモードを有効にする
9. このホーム画面を表示した状態で画面収録を開始し、2〜3秒静止してから`メモ`を開く。ホーム画面のアイコンから、準備済みの空の新規メモへ直接移動することを事前に確認する

ホーム画面からの開始部分は編集位置を決めやすくするために収録する。AppleはAppプレビューにアプリ内の映像を使用するよう求めているため、最終動画ではホーム画面部分を原則としてカットし、Sumibiの実際の機能が表示された場面から開始する。

## 動画構成

| 時間 | 画面と操作 | テロップ |
|---|---|---|
| 0〜3秒 | Sumibiのアイコンまたは設定画面から開始し、キーボード入力画面へ切り替える | `AI日本語キーボード Sumibi` |
| 3〜11秒 | `ashitaha shigoto no ato de tosyokan ni ikimasu.`と入力し、「変換」を押す。`明日は仕事のあとで図書館に行きます。`へ変換される様子を見せる | `ローマ字から、自然な日本語へ。` |
| 11〜17秒 | 英語の文に続けてローマ字を入力する。ローマ字部分だけを選択し、「変換」が「範囲を変換」に変わることを見せる。英語を残したまま、選択部分だけを日本語へ変換する | `英語はそのまま、選んだ範囲だけ変換` |
| 17〜23秒 | `osameru`を変換後、「さらに変換候補を取得」を押し、`収める`、`納める`、`治める`、`修める`などの候補を見せる | `同じ読みの表現も幅広く提案` |
| 23〜27秒 | Sumibiアプリの利用状況画面を開き、モデル別の変換回数・トークン数・概算利用料金を見せる | `AIの利用状況も確認` |
| 27〜30秒 | Sumibiの設定画面またはロゴで締める | `Sumibi` |

## 範囲変換の撮影用入力例

次の文章を入力する。

`Project update: ashita no kaigi ha gogo sanji kara desu.`

`ashita no kaigi ha gogo sanji kara desu.`の部分だけを選択し、「範囲を変換」を押す。変換後は、英語部分が変更されず、次のようにローマ字部分だけが日本語になることを見せる。

`Project update: 明日の会議は午後3時からです。`

AIの応答は一定ではないため、英語部分が維持され、選択部分だけが自然な日本語になることを本番前に確認する。

## 撮影前チェック

- [ ] Version `1.1.0`、Build `2`が実機にインストールされている
- [ ] iPhoneがLight Modeになっている
- [ ] ホーム画面の録画用ページに`Sumibi`と`メモ`だけが配置されている
- [ ] 両方のアプリに通知バッジが表示されていない
- [ ] `メモ`を開くと一覧を経由せず、本文が空の新規メモが直接表示される
- [ ] 既存のメモのタイトルや内容が録画に映らない
- [ ] APIキーとモデルが設定され、変換が成功する
- [ ] おやすみモードを有効にし、通知を停止する
- [ ] ステータスバーに不自然な警告や録画に不要な情報がない
- [ ] 入力先には個人情報を含まない新規文書を使用する
- [ ] 利用状況画面に公開したくないモデル名や数値がないことを確認する
- [ ] 各入力例を事前に試し、期待する候補が返ることを確認する
- [ ] 範囲変換で`Project update:`が変更されず、選択したローマ字部分だけが日本語になることを確認する
- [ ] `osameru`から`収める`、`納める`、`治める`、`修める`など複数の候補が返ることを確認する
- [ ] 操作間の待ち時間を短くし、30秒以内に収める

## 書き出し仕様

- 長さ：15〜30秒（目標27〜30秒）
- 向き：縦
- 解像度：886×1920ピクセル
- 映像：H.264、プログレッシブ、最大30fps、目標10〜12Mbps
- 音声：無音でもステレオAACの音声トラックを付ける。44.1kHzまたは48kHz
- 形式：`.mov`、`.m4v`または`.mp4`
- 最大ファイルサイズ：500MB
- ポスターフレーム候補：通常変換後の日本語とSumibiキーボードが同時に見える場面

## 編集時の注意

- 画面の拡大よりも、ネイティブUI全体が分かる構図を優先する
- 場面転換はカットまたは短いフェードに限定する
- テロップは無音自動再生でも読める大きさと表示時間にする
- 特定の価格、日付、季節に依存する表現を入れない
- 画面収録後、APIキー、通知、個人情報が一切映っていないことを全フレームで確認する
