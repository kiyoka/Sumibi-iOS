# Sumibi 1.2.0 App Store更新情報

## このバージョンの新機能

- 変換結果の言語・文体・句読点などを切り替えられる「文体プリセット」を追加
- プロンプトを使わない場合と使う場合の変換結果を、設定画面で比較できる機能を追加
- iOS 26以降で、変換キーと候補表示に炭火をイメージしたEmber Glass演出を追加
- キー入力、候補選択、変換中の表示をより楽しく分かりやすいアニメーションへ改善
- 削除キーの長押しやキー押下時の反応を調整
- その他、操作性と安定性を改善

## 変更点の詳細

### 文体プリセット

- 名前付きプリセットを最大3件まで保存可能
- 使用するプリセットまたは「使用しない」を選択可能
- 中国語（簡体字）、韓国語、英語、論文スタイルの例文を用意
- 論文スタイルでは、句読点を全角の「，」「．」へ統一する指示を利用可能
- 同じ入力をプロンプトなし／ありで変換し、かぎ括弧付きの等幅フォントで比較可能
- 使用中のプリセットをアプリ内の変換テストとキーボードの変換へ反映

### キーボードの表示と操作感

- iOS 26以降で、変換キーと候補ボタンにネイティブのLiquid Glassを使ったEmber Glass演出を追加
- 変換中に候補バーを横切るオレンジ色の走査光を追加
- キー押下後にオレンジ色の残光が自然に消える演出を追加
- 変換キーの色を入力文字数に応じて段階的に変化
- 候補確定時にボタンが弾むアニメーションを追加
- キー押下時の拡大・収縮アニメーションを調整
- 削除キーは1文字目をすぐ削除し、その後に連続削除を開始するよう改善
- iOS 26未満では従来の表示を維持
- 「視差効果を減らす」が有効な場合は、関連するアニメーションを省略

## App Store Connect登録時の確認

- 日本語と英語（アメリカ）の「このバージョンの新機能」を登録する
- 新しいキーボード外観が分かるスクリーンショットへ更新する
- 文体プリセット画面を追加のスクリーンショット候補として検討する
- Appプレビュー動画は現在のキーボード外観と一致するか確認する
- Version `1.2.0`、Build `3`のTestFlightビルドで最終確認する
