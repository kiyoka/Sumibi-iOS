# Sumibi 1.2.0 Appプレビュー制作案

## 方針

- 1.2.0の基本操作と主要な新機能を30秒以内で紹介する
- iPhone 14 Plusの実機をLight Mode・縦向きで画面収録する
- 通常変換ではiOS 26以降のEmber Glass演出が見える速度で操作する
- 各場面は別々に収録し、待ち時間や画面移動を編集で短くする
- 音声なしでも伝わる短いテロップを付ける
- APIキー、メールアドレス、通知、既存メモなどの秘密情報・個人情報を映さない
- 実際のアプリに存在しない動作や結果を合成しない

## 録画前の準備

1. iPhoneをLight Modeにする
2. ホーム画面の録画用ページへ`Sumibi`と`メモ`だけを置く
3. おやすみモードを有効にする
4. メモアプリは、一覧を経由せず空の新規メモが開く状態にする
5. SumibiアプリはAPIキーが見えない画面から開ける状態にする
6. APIキーとモデルを事前に設定し、変換できることを確認する
7. 韓国語の追加指示は保存せず比較できるよう、使用するプリセットを決めておく

## 収録する場面

### 場面1：通常変換

1. 空の新規メモを開く
2. `ashitaha shigoto no ato de tosyokan ni ikimasu.`と入力する
3. 「変換」を押す
4. Ember Glassの光が流れ、自然な日本語へ変換されるところまで待つ
5. 変換結果と候補バーを約2秒表示する

テロップ：`ローマ字から、自然な日本語へ。`

### 場面2：範囲変換

1. 場面1の文章をすべて削除する
2. `Project update: ashita no kaigi ha gogo sanji kara desu.`と入力する
3. ローマ字部分だけを選択する
4. 「範囲を変換」を押す
5. `Project update:`を残したまま、日本語へ変換された結果を約2秒表示する

テロップ：`選んだ範囲だけ変換`

### 場面3：追加候補

1. 場面2の文章をすべて削除する
2. `osameru`と入力して変換する
3. 「さらに変換候補を取得」を押す
4. `収める`、`納める`、`治める`、`修める`などが並ぶまで待つ
5. 候補バーを約2秒表示する

テロップ：`同じ読みの表現も幅広く提案`

### 場面4：プリセット比較（今回の動画では省略）

1. Sumibiアプリの「文体プリセット」から任意のプリセットを開く
2. 「例文から選ぶ」から「韓国語」を選ぶ
3. 比較文に`ashita made ni kakunin shi, kekka wo houkoku shite kudasai.`を入力する
4. 「設定なし／ありを比較」を押す
5. 日本語と韓国語の結果が同時に見える位置へ移動する
6. 比較結果を約3秒表示する
7. 撮影後は保存せず戻る

テロップ：`出力言語もプリセットで切り替え`

1.2.0の初回提出用動画では、この場面を収録していないため省略する。韓国語プリセットの比較はスクリーンショット5枚目で紹介する。

## 編集後の構成（約30秒）

| 時間 | 内容 |
| --- | --- |
| 0〜9秒 | 通常変換とEmber Glass |
| 9〜20秒 | 範囲変換 |
| 20〜30秒 | `osameru`の追加候補を表示して終了 |

## 撮影後の確認

- [ ] APIキー、個人情報、通知が一切映っていない
- [ ] 既存メモの一覧や内容が映っていない
- [ ] Ember Glassの光が途中で不自然に切れていない
- [ ] 範囲変換で英文部分が変更されていない
- [ ] 追加候補が複数表示されている
- [ ] 韓国語プリセットの比較はスクリーンショット5枚目で確認できる
- [ ] 編集後の長さが30秒以内である
- [ ] 音声トラックを含み、App Store Connectが受け付ける形式である

## 書き出し仕様

- 向き：縦
- 解像度：886 × 1920ピクセル
- 映像：H.264、プログレッシブ、最大30fps
- 音声：無音でもステレオAACの音声トラックを付ける
- 形式：`.mov`、`.m4v`または`.mp4`
- 最大ファイルサイズ：500MB
- 保存先：`docs/assets/app-store/1.2.0/`
