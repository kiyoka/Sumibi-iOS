## 詳細説明（日本語案）

```text
英字QWERTYキーボード1画面だけで、キーボードを切り替えずに日本語と英語を入力できるAI日本語キーボードです。ユーザーはOpenAI互換APIのアクセスキー、モデル、送信先を自身で準備して設定します。

バージョン1.2.0では、変換結果の言語、文体、句読点、形式を切り替えられる文体プリセットを追加しました。最大3件を保存でき、設定なしの場合との変換結果をその場で比較できます。最新のAIモデルを利用することで、ローマ字に多少のミスタイプがあっても入力意図をくみ取り、自然な文章へ補正できます。

iOS 26以降では、炭火をイメージしたEmber Glass演出を変換キーと候補表示へ追加しました。入力から変換、候補選択までの状態を、色、光、動きで分かりやすく表現します。
```

## Detailed Description (English Draft)

```text
Sumibi is an AI-powered Japanese keyboard that lets people type both Japanese and English from a single QWERTY layout without switching keyboards. Users bring and configure their own OpenAI-compatible API key, model, and endpoint.

Version 1.2.0 adds writing-style presets for output language, tone, punctuation, and formatting. Users can save up to three presets and compare the same conversion with and without a prompt before choosing one. With a capable AI model, Sumibi can infer intent from romaji containing minor typing mistakes and refine it into natural text.

On iOS 26 and later, the new Ember Glass presentation brings a distinctive charcoal-fire-inspired glass treatment to the Convert key and candidate controls. Color, light, and motion communicate the flow from typing through conversion and candidate selection.
```

## Helpful Details（500文字以内の案）

```text
Sumibiは、かな入力へ切り替えず、英字QWERTYの1画面で日本語を入力する独自の操作体験を提供します。ユーザーが選んだOpenAI互換APIへ端末から直接接続し、Sumibi運営のサーバーを経由しません。API送信前の明示的な同意、端末Keychainへのキー保存、視差効果を減らす設定への対応を備えています。1.2.0では文体プリセットとEmber Glass演出を追加し、AI変換をより自分向けで、状態の分かりやすい体験にしました。
```

## 提出手順

1. App Store ConnectでSumibiを開く
2. サイドバーの「フィーチャー」から「ノミネート」を開く
3. 「+」から「ノミネートを作成」を選ぶ
4. Nomination Typeに`App Enhancements`を選ぶ
5. 詳細説明と公開予定日を入力する
6. Related Apps、Platform、Regions、Localizations、Supplemental Materials、Helpful Detailsを確認する
7. まず下書き保存し、1.2.0の公開予定日と素材が確定してから提出する
