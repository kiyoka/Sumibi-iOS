# Sumibi-iOS

<img src="SumibiApp/Assets.xcassets/AppIcon.appiconset/AppIcon.png" alt="Sumibiアプリアイコン" width="160">

iOS向けの日本語入力IME（カスタムキーボード）です。ローマ字または英語で入力し、LLM（大規模言語モデル）を使って自然な日本語へ変換します。

Emacs版の [Sumibi](https://github.com/kiyoka/Sumibi) が持つ「モードレス」な入力方式（かな漢字変換モードへの切り替えを意識せず、英字QWERTYのまま日本語を書ける方式）を、iPhone / iPadのカスタムキーボード拡張として実現するプロジェクトです。

## 特徴

- **モードレスな入力** — 英字QWERTY配列のまま入力し、専用の変換キーを押すだけで日本語に変換されます。
- **LLMによる変換** — OpenAI互換API（Chat Completions形式）を利用して、ローマ字・英語の文章を自然な日本語に変換します。エンドポイントやモデルは利用者が自由に設定できます。
- **Undo対応** — 変換結果はいつでも原文に戻せます。
- **候補バー** — 最初の変換結果をすぐに挿入しつつ、「さらに変換候補を取得」で通常変換・タイプミス補正・全ひらがな・全カタカナ・漢字多めなど複数の候補を追加取得できます。
- **クリップボード読込** — 候補バーのボタンから、クリップボードの内容をそのままカーソル位置に挿入できます。
- **プライバシー重視** — 変換キーを押した時だけ文字列を送信し、キー入力や変換対象をログへ保存しません。APIキーは共有Keychainに保存し、iCloud同期やバックアップの対象外とします。

## 構成

| ターゲット | 役割 |
| --- | --- |
| `SumibiApp` | コンテナアプリ。プロバイダー（エンドポイント／モデル／APIキー）の設定、キーボードの有効化案内、変換テスト画面を提供します。 |
| `SumibiKeyboard` | キーボード拡張本体。QWERTYキー、候補バー、入力追跡、変換リクエストの実行、Undoを担当します。 |
| `SumibiCore` | アプリとキーボード拡張が共有するSwiftパッケージ。変換リクエスト／レスポンスのモデル、入力追跡ロジック、OpenAI互換HTTPクライアントなどを含みます。 |

コンテナアプリとキーボード拡張は、機密情報以外の設定をApp Group経由の`UserDefaults`で共有します。APIキーは共有Keychain（`kSecAttrAccessibleWhenUnlockedThisDeviceOnly`、`kSecAttrSynchronizable`無効）に保存し、キーボード拡張は変換時に読み取るだけで書き込みは行いません。

## 動作要件

- **ローカルで実機ビルドする場合の注意** — このプロジェクトは、コンテナアプリとキーボード拡張の間で設定やAPIキーを共有するためにApp Groupsを使用しています。現在の構成のままiPhone / iPadへインストールして動作させるには、実機を所有しているだけでは足りず、原則として有料の[Apple Developer Program](https://developer.apple.com/jp/support/compare-memberships/)への年間登録が必要です。無料のPersonal Teamでは利用できる機能やプロビジョニングに制限があり、App Groupsを含む本プロジェクトをそのまま動作させられない場合があります。登録条件や料金は変更される可能性があるため、Appleの最新情報を確認してください。
- 変換にはネットワーク通信と共有Keychainへのアクセスが必要なため、設定アプリでキーボードの「フルアクセスを許可」を有効にする必要があります。
- 変換にはOpenAI互換API（OpenAI本家、または互換のローカル／クラウドサーバー）のエンドポイントとAPIキーが必要です。エンドポイントを`/v1`または完全な`/chat/completions` URLとして指定することもできます。

## セットアップ

1. Xcodeで `Sumibi-iOS.xcodeproj` を開きます。
2. `SumibiApp` をビルド・実行します。
3. アプリ内でOpenAI互換APIのエンドポイント・モデル名・APIキーを設定します。
4. 設定アプリの「キーボード」からSumibiキーボードを追加し、「フルアクセスを許可」を有効にします。
5. 任意のアプリでSumibiキーボードに切り替え、ローマ字や英語を入力してから変換キーを押すと日本語に変換されます。

## 現時点の範囲

初回リリース（MVP）では以下を対象としています。

- 英字QWERTY配列でのローマ字・英語入力と専用変換キー
- OpenAI互換プロバイダーによる日本語変換と候補バー
- Undo、キャンセル、フルアクセス未許可・通信エラー時の明確な表示

フリック入力配列、アンビエント変換、ローカルMozcによる仮確定、クラウド同期、ユーザー辞書、音声入力などは今回のスコープ外です。詳細な設計や状態遷移は [`docs/DESIGN.md`](docs/DESIGN.md) を参照してください。
